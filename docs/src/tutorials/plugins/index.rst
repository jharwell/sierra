================
Extending SIERRA
================

SIERRA's behaviour is almost entirely driven by plugins. This section covers
how to write new ones.

Before writing a plugin of any type, read :ref:`tutorials/plugins/devguide` for
the conventions all plugins must follow, and :ref:`tutorials/plugins/external`
for how SIERRA discovers and loads plugins at runtime. Then follow the tutorial
for the plugin type you need:
