===============
Getting Started
===============

SIERRA is a framework for automating large-scale computational experiments
across simulation, real-robot, and cloud environments. This section takes you
from zero to a running experiment.

Follow the pages in order, or jump to the one that matches where you are:

.. list-table::
   :header-rows: 0
   :widths: 30 70

   * - :doc:`installation`
     - Install SIERRA and its dependencies. Start here.

   * - :doc:`trial`
     - Run a working experiment using a pre-built sample project — no plugin
       setup required. The fastest way to see SIERRA in action.

   * - :doc:`setup`
     - Connect SIERRA to your own code by creating a project plugin, then
       invoke SIERRA for the first time.

   * - :doc:`why-sierra`
     - Concrete use cases showing the kinds of problems SIERRA was designed to
       solve. Read this if you are evaluating whether SIERRA fits your workflow.
