============
Architecture
============

These pages explain how SIERRA works internally. They are most useful
when writing plugins or contributing to the core, but also help explain
why SIERRA behaves the way it does in edge cases.

- :ref:`arch/execution-model` — How SIERRA manages processes,
  subprocesses, and execution across pipeline stages.

- :ref:`arch/plugin-system` — How plugins are discovered, loaded,
  and composed at runtime.

- :ref:`arch/deep-dive` — Detailed internals for contributors and
  advanced users.
